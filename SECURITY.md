# Sécurité

NerdMC transmet les messages du tchat Minecraft vers Discord. Le token Discord et les identifiants de connexion Minecraft ne doivent jamais être commités (voir `config.json.example`).

## Signaler une vulnérabilité

- Ne publiez **pas** la vulnérabilité dans une issue publique.
- Utilisez la [signalisation privée de vulnérabilité GitHub](https://github.com/Estemobs/NerdMC/security/advisories) (Security tab → Report a vulnerability).

Vous recevrez un accusé de réception sous quelques jours. Merci de ne pas exploiter la faille et de donner un délai raisonnable avant toute divulgation.
